## The entry

> I'm away. Your email is queued behind 4,096 unread messages and one very confident hallucination about a meeting that never happened.

133 characters. The joke: the queue is 4,096 deep, and one of the things waiting in it is a hallucination — a meeting that never happened. Machine voice carries the punch.

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), no network, no secrets.

```sh
node main.ts
```
